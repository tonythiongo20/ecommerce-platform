# 🛒 ShopHub – Full-Stack E-Commerce Platform

A modern e-commerce application built with **Next.js 14**, **Prisma**, **PostgreSQL**, **JWT**, and **Stripe**.

## Features
- Product catalog with categories
- Shopping cart
- User authentication (Register / Login)
- Stripe Checkout
- Responsive design

## Tech Stack
- Next.js 14 (App Router) + TypeScript + Tailwind CSS
- Prisma + PostgreSQL
- JWT Authentication
- Stripe
