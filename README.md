# 🛒 ShopHub – Full-Stack E-Commerce Platform

A modern full-stack e-commerce application built with **Next.js 14**, **Prisma**, **PostgreSQL**, **JWT Authentication**, and **Stripe**.

> Complete online store with product catalog, shopping cart, user authentication, and secure payment integration.

---

## ✨ Features

- Product listing & detailed product pages
- Shopping cart with quantity management
- User authentication (Register / Login)
- Stripe payment integration
- Responsive design (mobile-friendly)
- Type-safe codebase with TypeScript
- Prisma ORM with PostgreSQL

---

## 🛠️ Tech Stack

**Frontend**
- Next.js 14 (App Router)
- React
- TypeScript
- Tailwind CSS

**Backend**
- Next.js API Routes
- PostgreSQL
- Prisma ORM

**Auth & Payments**
- JWT Authentication (httpOnly cookies)
- bcrypt
- Stripe Checkout

---

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL
- Stripe account (test keys)

```bash
# Clone the repository
